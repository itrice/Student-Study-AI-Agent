# 子鱼学习AI · 品牌标识

## 品牌定位

子鱼学习AI 是面向小学 3～6 年级与初中 3 年的全学科 AI 学习伙伴。标识需要同时覆盖低龄段与青春期前段，因此采用“亲和但不幼稚、聪明但不冰冷”的方向。

## 标志含义

- 鱼：取自“子鱼”，代表灵动、记忆与持续游动；也呼应“授人以渔”的学习方法。
- 书页：鱼身由三笔书页线构成，中间的脊线同时是书脊和鱼的身体中线。
- 星芒：代表 AI 的洞察、启发与即时反馈。
- 珊瑚色尾鳍：保留儿童教育的温度与行动感；深绿色主体用于建立稳定和成长感。

## 使用规范

- 最小尺寸：标准横向组合不小于 240px 宽；紧凑组合不小于 160px 宽；App 图标不小于 48px；独立鱼标不小于 32px。
- 安全边距：标志四周至少留出 0.5 个 App 图标宽度的空白，不要贴边。
- 背景：浅色背景使用标准版；深色背景使用反白版；不要放在复杂照片或低对比纹理上。
- 不得拉伸、旋转、改色、加描边或投影，不要拆分鱼标与字标，不要单独改变“AI”的颜色。
- 中文字标使用 Microsoft YaHei / PingFang SC / Noto Sans SC；对外印刷或交付设计源文件前，建议将文字转为轮廓。
