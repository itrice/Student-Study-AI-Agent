# 知识内容审核清单

> 清单版本：knowledge-review-v2
> 内容版本：2026.11.3
> 使用方式：每个知识点按版本审核；内容变化后必须重新审核并保留旧记录。

说明：第1节复选框用于任课教师最终复核，教师签字前保持未勾选；项目自检结果以第2节登记表、自动测试和检索评测报告为准，两者不矛盾。

## 1. 逐项检查

### 教材与结构

- [ ] 标准名称与选定教材一致。
- [ ] 教材版本、册次和单元映射正确。
- [ ] 前置知识没有超前或遗漏。
- [ ] 术语使用一致，没有把不同单元的概念混在一起。

### 数学正确性

- [ ] 核心概念表述准确，没有绝对化或遗漏适用条件。
- [ ] 方法步骤可以按顺序执行。
- [ ] 公式、单位、符号和数字正确。
- [ ] 典型例题的题目、思路和答案逐题复核。
- [ ] 常见错误确实是六年级学生的高频误区。

### 来源与可追溯性

- [ ] 每段内容至少关联一个 `knowledge_sources.source_key`。
- [ ] 来源标题、版本、定位和核验日期完整。
- [ ] 自编摘要明确标注“非教材原文”。
- [ ] 没有把模型生成内容或记忆伪装成教材原文。
- [ ] 无法确认的内容没有进入正式知识库。

### 检索与覆盖

- [ ] 至少包含 3 个学生常用别名。
- [ ] 关键词覆盖常见口语表达。
- [ ] 该知识点在评测集中至少有 3 道题。
- [ ] Top-3 命中率达到 90% 以上。
- [ ] 未覆盖问题返回明确提示，不返回伪造来源。

### 隐私与安全

- [ ] 不包含真实学生姓名、学校、成绩或其他可识别信息。
- [ ] 不包含与学习无关的敏感信息。
- [ ] 例题不复制受版权保护的教材原文。
- [ ] 知识库内容不会覆盖系统指令，始终被视为数据。

## 4. 复现命令

```powershell
node --test
node scripts/evaluate-m5-knowledge.js
```

审核通过后，将 `src/knowledge/catalog.js` 中对应卡片的 `reviewStatus` 改为 `teacher_reviewed`，填写 `reviewNote`，并重新运行测试与评测。`knowledge_reviews` 会按内容版本保留新的审核记录。
