# UI 自测与验收清单

> 清单版本：ui-acceptance-v1
> 适用页面：今日学习、开始复习、我的错题与修改弹窗、知识点地图、学习反馈打卡月历与当日完成情况弹窗

## 1. 字号与可读性

- [ ] 正文、题目、解析、知识片段和提示内容不小于 `16px`。
- [ ] 按钮、输入框、下拉框和主要辅助文字不小于 `15px`。
- [ ] 标签、徽章、时间、来源、引用和其他需要阅读或操作的元信息不小于 `15px`。
- [ ] `12px` 仅限纯装饰图形或角标，且不承载用户需要理解的信息。
- [ ] 全站不存在 `8px`、`9px`、`10px`、`11px`、`12px`、`13px`、`14px` 的阅读文本。
- [ ] 小字号信息不依赖浅色和低对比度来维持层级，长文本保持 `1.6` 以上行高。
- [ ] 标签、徽章和按钮放大后可以换行，不使用裁切或省略号隐藏操作名称。

## 2. 缩放与布局

- [ ] 桌面 `1440px` 宽度下，四列统计卡、主内容区和侧栏对齐正常。
- [ ] `125%` 缩放（等效约 `1152px`）下，无横向滚动条、无文字重叠。
- [ ] `150%` 缩放（等效约 `960px`）下，统计卡自动降为两列，表单和操作按钮不挤压。
- [ ] 窄屏 `375px` 下，侧栏可打开，题目、弹窗和知识卡片保持单列可读。
- [ ] 修改弹窗在窄屏和放大后仍可滚动；底部“取消/保存修改”始终可见。
- [ ] 长题目、长标签和长来源引用可以换行，不撑破卡片或产生页面级横向溢出。

## 3. 交互可用性

- [ ] 修改弹窗只能通过关闭按钮、取消按钮或保存成功关闭。
- [ ] 点击遮罩或按 `Esc` 不会丢失正在编辑的内容。
- [ ] 保存成功提示不会被页面刷新失败覆盖；刷新失败时明确提示数据已保存。
- [ ] 答错或部分正确时停留在当前题，显示客观判题结果和当前尝试状态，不自动跳题。
- [ ] 答错或部分正确后不自动调用 AI 提示，不自动展示 AI 步骤分析、诊断、订正思路或参考答案。
- [ ] 只有主动点击“查看提示”后才加载分级提示；未点击前不泄露答案。
- [ ] 只有整题全部小问正确才短暂显示“答对”并自动进入下一题；部分正确不自动切换。
- [ ] 最后一题整题答对后进入复习完成态。
- [ ] 复习页和全屏专注层都有“上一题/下一题”；首题禁用上一题，末题禁用下一题。
- [ ] 手动切换按当前今日复习队列顺序进行，不提交作答；切换回来恢复本次会话未提交输入，以及已查看的提示等级和提示内容。
- [ ] 移动端与平板（`390×844`、`834×1194`）的上一题、下一题、全屏和修改题目按钮触控高度不小于 `44px`。
- [ ] 答错后仍可点击“修改题目”。
- [ ] 键盘焦点可见，主要按钮和表单控件可正常聚焦和操作。

## 4. 学习反馈打卡月历

- [ ] 学习反馈页日/周报下方有全宽“打卡记录”卡片，默认当前月；上个月、下个月、回到本月可用。
- [ ] 未来日期和未来月份置灰且不可进入；当天日期有高亮。
- [ ] 月历顶部显示“本月打卡 X 天 · 完成 Y 题 · 正确 Z 题”；每格显示日期、完成题数、正确题数，无记录为浅色。
- [ ] 每个日期格触控宽度和高度均不小于 `44px`，文字不小于 `15px`；移动端 `390×844`、平板 `834×1194`、桌面 `1280×900` 无横向溢出。
- [ ] 今日小结的“查看今日完成情况”和点击任意日期打开同一个“X月X日完成情况”弹窗。
- [ ] 弹窗显示完成题数、作答次数、正确题数、待订正题数；同题多次作答聚合为一行，按最近作答时间倒序。
- [ ] 弹窗不展示正确答案、学生原始答案或提示正文；空日显示“这一天还没有作答记录”。
- [ ] 弹窗支持关闭按钮、`Esc`、点击遮罩关闭，关闭后焦点返回触发按钮；移动端弹窗内容可滚动。
- [ ] 月历与日明细数字一致：完成题数按当天去重题目，正确题数取每题当天最近一次是否为整题完全正确，partial/incorrect 不算正确。
- [ ] 日/周报与复习流程行为不受影响。

## 5. 自动化检查

```powershell
node --check public/app.js
node --test
node --test test/ui-readability.test.js
node --test test/feedback-calendar.test.js
node --test test/feedback-calendar-ui.test.js
```

`test/ui-readability.test.js` 会检查字号基线、控件最小字号，以及放大文字后关键容器的换行或滚动兜底。浏览器检查还需按第 1～4 节在 `1440px`、`1152px`、`960px` 和 `375px` 宽度逐页确认。
