# UI 自测与验收清单

> 清单版本：ui-acceptance-v1
> 适用页面：今日学习、开始复习、我的错题与修改弹窗、知识点地图

## 1. 字号与可读性

- [ ] 正文、题目、解析、知识片段和提示内容不小于 `16px`。
- [ ] 按钮、输入框、下拉框和主要辅助文字不小于 `14px`。
- [ ] 标签、徽章、时间、来源、引用和其他次要元信息不小于 `12px`。
- [ ] 全站不存在 `8px`、`9px`、`10px`、`11px` 的阅读文本。
- [ ] 小字号信息不依赖浅色和低对比度来维持层级，长文本保持 `1.6` 以上行高。
- [ ] 标签、徽章和按钮放大后可以换行，不使用裁切或省略号隐藏操作名称。

## 2. 缩放与布局

- [ ] 桌面 `1440px` 宽度下，四列统计卡、主内容区和侧栏对齐正常。
- [ ] `125%` 缩放（等效约 `1152px`）下，无横向滚动条、无文字重叠。
- [ ] `150%` 缩放（等效约 `960px`）下，统计卡自动降为两列，表单和操作按钮不挤压。
- [ ] 窄屏 `375px` 下，侧栏可打开，题目、弹窗和知识卡片保持单列可读。
- [ ] 修改弹窗在窄屏和放大后仍可滚动；底部“取消/保存修改”始终可见。
- [ ] 长题目、长标签和长来源引用可以换行，不撑破卡片或产生页面级横向溢出。

## 3. 交互可用性

- [ ] 修改弹窗只能通过关闭按钮、取消按钮或保存成功关闭。
- [ ] 点击遮罩或按 `Esc` 不会丢失正在编辑的内容。
- [ ] 保存成功提示不会被页面刷新失败覆盖；刷新失败时明确提示数据已保存。
- [ ] 键盘焦点可见，主要按钮和表单控件可正常聚焦和操作。

## 4. 自动化检查

```powershell
node --check public/app.js
node --test
node --test test/ui-readability.test.js
```

`test/ui-readability.test.js` 会检查字号基线、控件最小字号，以及放大文字后关键容器的换行或滚动兜底。浏览器检查还需按第 1～3 节在 `1440px`、`1152px`、`960px` 和 `375px` 宽度逐页确认。
