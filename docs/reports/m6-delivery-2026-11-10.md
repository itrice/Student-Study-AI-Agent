## 1. 交付范围

- 四状态掌握模型：`new`、`practicing`、`mastered`、`relearning`。
- 连续两次无提示独立答对后进入 `mastered`；已掌握题答错或提示后答对回到 `relearning`。
- schema v9 掌握证据：记录前后状态、结果、连续独立答对次数、复习计划、原因和明细；v9 为零作答旧题补齐证据。
- 每次作答、改题和复习计划变更写入可追溯证据；模型评价不能直接修改掌握状态。
- 到期复习队列、优先级和重启一致性。
- 日总结、家长可读周报、掌握变化、独立作答与提示依赖统计。
- 学习反馈页面、四状态筛选和知识检索重置。

## 2. 数据与接口

数据库升级到 `schema v9`。v8 扩展 `mastery_evidence`，保留历史证据并新增：

- `previous_status`
- `next_status`
- `outcome`
- `consecutive_independent_correct`
- `review_schedule_id`
- `reason`
- `detail_json`

v9 新增 `legacy_mastery_evidence_backfill`，为没有作答记录、也没有掌握证据的旧题写入一条
`legacy_seed` 证据（`attempt_id` 为空），保证升级后每道旧题都能追溯掌握状态；迁移使用
`NOT EXISTS` 保护，重复执行不会重复写入。

新增只读 HTTP 接口：

- `GET /api/feedback/daily?date=YYYY-MM-DD`
- `GET /api/feedback/weekly?end=YYYY-MM-DD`
- `GET /api/review/queue?limit=5`
- `GET /api/mistakes/:id/evidence`

## 5. 首轮验收阻断项修复

1. **P1：v7 零作答旧题没有掌握证据**
   - 新增 v9 迁移 `legacy_mastery_evidence_backfill`，为无证据旧题补 `legacy_seed`。
   - 保持 v8 迁移 SQL 不变，避免已升级数据库的迁移校验和失效。
2. **P2：历史回填被周报误认为“本周刚掌握”**
   - 掌握变化统计排除 `legacy_backfill`、`legacy_seed` 和 `rule_version = 'legacy'`。
   - 日总结/周报在存在历史证据时明确说明“历史导入的掌握证据不计入统计”。
3. **P2：只改整题解析会重置掌握并清空小问提示/解析**
   - 只有题目、答案、知识点或判题相关小问内容变化才重置掌握。
   - 仅修改整题解析或小问提示/解析时，保留掌握状态和小问数据。

新增测试名称：

- `v7 零作答旧题升级后补齐掌握证据且不重复回填`
- `历史回填证据不计入掌握变化，并明确历史导入边界`
- `只改整题解析不会重置掌握，并保留小问提示与解析`
