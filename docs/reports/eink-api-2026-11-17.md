# 电子墨水屏接口验收报告

> 日期：2026-11-17
> 分支：`codex/eink-frame-api`
> 结果：自动化通过，待真机验收

## 自动化结果

- 电子墨水屏专项：5 / 5 通过。
- 项目完整测试：213 / 213 通过。
- HTTP 实测页帧：48000 字节。
- 响应无 `Content-Encoding`，`Content-Type: application/octet-stream`，
  `Content-Length: 48000`。
- 强 `ETag` 与 `X-Etag` 一致；携带 `If-None-Match` 的第二次请求返回 304，
  body 为 0 字节且没有 48000 的 `Content-Length`。
- 修改答案后 ETag 变化；替换裁剪后 ETag 变化。
- PNG 预览解码为 800×480，与同参数帧逐像素一致。
- 题目页构建结果不含正确答案、学生答案、解析、错因或提示。
- 手机 JPEG EXIF Orientation 6 只旋转一次。
- 附件文件缺失时仍返回 48000 字节文字页，并记录 `EINK_PHOTO_FALLBACK`。
- 队列 `count` 为全部到期数；`limit=1` 边界、非法值和连续 `index` 已验证。
- 页面只读请求前后，作答、提示和复习计划记录数不变。

## 文件格式证据

位打包单元测试：

```text
8×1 画布，最左 1 像素为黑
输出 [0x7f]
```

这同时验证了每行 MSB 在左，以及 `0=黑、1=白` 的位定义。
