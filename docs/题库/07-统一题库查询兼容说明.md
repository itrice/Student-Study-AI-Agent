# 统一题库查询兼容说明

> 日期：2026-11-25  
> 范围：Question 统一查询、错题兼容接口与题库页面

## 1. 查询入口

统一题库以 `mistakes` 表作为唯一正式题目事实，不复制题目数据。

| 入口 | 语义 | 响应 |
|---|---|---|
| `GET /api/questions` | 默认返回全部题目 | `{ total, questions }` |
| `GET /api/questions?category=mistake` | 只返回错题分类 | `{ total, questions }` |
| `GET /api/questions?category=<分类>` | 返回指定分类的题目 | `{ total, questions }` |
| `GET /api/mistakes` | 错题兼容外壳，默认全部错题 | 题目数组 |
| `GET /api/mistakes?status=<状态>` | 兼容状态筛选 | 题目数组 |

## 2. 分类与遗留数据

- `question_categories` 是题目分类事实来源。
- `mistake` 表示错题，`normal` 表示普通题；同一题可以拥有多个分类。
- 没有任何分类记录的遗留题目，在兼容视图中按 `mistake` 处理。
- 题目同时拥有多个分类时只会返回一条题目记录，不会复制行、附件、小问或答案。

## 3. 错题兼容接口

`GET /api/mistakes` 是 `GET /api/questions?category=mistake` 的读取适配器：

- 题目 ID、题干、附件、小问摘要和学习状态保持一致。
- `status` 参数继续支持 `all`、`new`、`practicing`、`relearning`、`mastered`。
- 非法 `status` 仍按 `all` 处理。
- 旧响应外壳保持为题目数组，不要求现有手机端修改调用方式。

## 4. 复习队列

复习到期数量、下一题和队列只读取分类为 `mistake` 的题目；没有分类的遗留题目仍按错题处理。
普通题即使存在旧复习计划，也不会进入今晚范围内的错题复习队列。

## 5. 页面

题库页面默认通过 `GET /api/questions` 展示全部题目，并提供“全部题目 / 错题”快捷分类筛选。
切换到错题时通过 `GET /api/questions?category=mistake` 读取，不调用第二份数据或复制列表。

## 6. 不兼容变更

本轮不包含：

- 将物理表 `mistakes` 改名为 `questions`；
- 删除 `/api/mistakes`；
- 新建题目副本或重建学习数据；
- 新筛选器、编辑器或 E-Ink 专属功能。
