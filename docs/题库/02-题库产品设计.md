# 题库产品设计

> 版本：1.1
> 日期：2026-11-24
> 状态：产品设计基线，已纳入内部 OCR 方案
> 关联需求：[拍照批量识别与统一题库产品需求](01-产品需求-拍照批量识别与统一题库.md)

## 1. 设计目标

题库不是只保存错题的表单，也不只是“我的错题”页面的另一个入口。它是学生长期积累、复习和整理题目的统一空间。

题库需要解决四个问题：

1. 学生从哪里快速找到需要的题。
2. 一道包含文字、公式、图片、选项和小问的题如何完整保存。
3. 错题、经典题、扩展题等不同用途如何区分，又不产生重复数据。
4. 学习状态、标准答案、题目来源和原始图片如何保持可追溯。

## 2. 产品定位

### 2.1 一个题库，多种用途

产品只有一个正式题库。以下内容都是题目的属性或分类，不是独立题库：

- 错题。
- 普通题。
- 经典题。
- 扩展题。
- 易错题。
- 重点题。
- 自定义分类。
- 某个知识点下的题。
- 某次作业或试卷中的题。

同一道题可以同时属于“错题”“易错题”和“重点题”，但只保存一条题目记录。

### 2.2 扫描候选不是题库题目

```text
一次扫描
  → 多道暂时候选
  → 用户选择
  → 用户确认答案和来源
  → 正式导入题库
```

识别完成、系统认为答错、用户打开了候选详情，都不代表已经进入题库。只有用户选择并完成导入后才成为正式题目。

### 2.3 题库服务于学习闭环

题库负责题目本身；学习模块负责作答、提示、掌握状态和复习计划。题库中的题目应能被手机复习和电子墨水屏读取，但题库不保存各端自己的题目副本。

## 3. 设计原则

### 3.1 一份正式事实

- 题目内容只有一个正式来源。
- 错题筛选和普通题筛选都读取同一份题目。
- 学习记录通过题目身份关联，不因分类变化丢失。
- 移动端、电子墨水屏和后续教师端读取同一道题。

### 3.2 内容优先于附件

图片是题目内容的一部分，可以出现在题干、材料、选项或小问之间。产品不能假设题目只有一段文字。

题目内部应保持阅读顺序：

```text
文字 → 公式 → 图片 → 选项 → 小问 → 更多文字或图片
```

### 3.3 原图和复习图分离

- 原图用于追溯，不能被自动处理覆盖。
- 优化图用于提高电子墨水屏阅读效果。
- 裁剪图用于聚焦题目区域。
- 用户可以查看原图、比较优化结果并恢复原图。

### 3.4 建议和确认分离

- 系统可以建议题型、标准答案和来源。
- 用户确认后的答案才是最终标准。
- 系统建议与用户确认冲突时，保留冲突标记和审计记录。
- 系统找不到可靠答案或来源时，应明确留空，不得猜测。

### 3.5 分类不能替代学习状态

“错题”或“经典题”说明题目用途；“未学习”或“已掌握”说明学习进度。两者不能混成一个字段。

## 4. 题库信息架构

### 4.1 一级导航

建议题库页面包含以下入口：

- 全部题目。
- 错题。
- 经典题。
- 扩展题。
- 易错题。
- 待复核。
- 我的分类。

这些入口是预设筛选，不创建独立数据集合。

### 4.2 题库首页

首页默认展示全部正式题目，至少包括：

- 搜索框。
- 分类筛选。
- 题型筛选。
- 学习状态筛选。
- 来源筛选。
- 内容完整度筛选。
- 待复核答案筛选。
- 排序。
- 题目卡片或列表。
- 拍照导入和手动新增入口。

### 4.3 题目卡片

卡片应帮助用户快速判断“要不要打开这道题”，建议展示：

- 题目摘要或清晰缩略图。
- 题型。
- 学科和知识点。
- 分类标签。
- 学习状态。
- 题目来源及确认状态。
- 标准答案是否待复核。
- 内容是否完整。
- 是否支持电子墨水屏单页显示。
- 最近编辑时间。

长题干和大量标签不得挤占主要空间，默认只展示能帮助筛选的关键信息。

### 4.4 题目详情

详情页至少分为：

1. 题目内容。
2. 作答与答案。
3. 来源和知识点。
4. 分类和学习状态。
5. 图片与原图。
6. 修订记录。

题目内容必须按真实阅读顺序显示。答案和解析应放在独立区域，复习题目页默认不显示。

### 4.5 题目编辑

编辑页面应支持：

- 修改题干、公式、图片、表格和选项。
- 调整内容块顺序。
- 增加、删除、重排小问。
- 修改每个小问的题型和作答方式。
- 修改答案、可接受答案和答案变体。
- 确认或修改题目来源。
- 管理分类标签。
- 切换复习时使用的图片版本。

修改题型、选项或小问结构时，系统应提示旧答案可能需要重新对应。

## 5. 题目内容模型

从产品角度，一道完整题目由以下部分组成。

### 5.1 基本信息

- 产品内部的题目身份。
- 扫描临时编号或原始题号，仅作来源定位。
- 学科、年级、知识点。
- 题型。
- 难度，可选。
- 分类标签。
- 学习状态。
- 内容完整度。
- 来源和来源确认状态。

### 5.2 有序内容

- 文字段落。
- 数学公式。
- 图片和几何图。
- 表格。
- 材料或阅读文本。
- 选择题选项。
- 小问。

每个图片和表格应有自己的阅读位置，不允许统一退化为题目末尾附件。

### 5.3 答案

- 学生原答案。
- 系统建议标准答案。
- 用户最终确认的标准答案。
- 可接受答案和答案变体。
- 解析或订正记录，可选。
- 标准答案复核状态。
- 系统建议与最终答案不一致标记。

### 5.4 来源

建议来源信息包括：

- 来源类型：教材、教辅、试卷、题库、教师创建或用户自定义。
- 来源名称。
- 版本或年份。
- 章节。
- 页码。
- 原题号。
- 用户确认状态。
- 人工核验备注。

产品只把用户确认的来源作为正式来源。未确认候选应明确标记。

### 5.5 图片

- 完整扫描原图。
- 当前题在扫描原图中的区域。
- 人工裁剪图。
- 自动优化图。
- 去作答痕迹派生图，可选。
- 当前复习显示图。

### 5.6 审计

- 创建方式和来源扫描批次。
- 内容和答案修订历史。
- 来源确认和冲突处理记录。
- 图片替换和恢复记录。

## 6. 题型与作答方式

### 6.1 题型

- 单选题。
- 多选题。
- 判断题。
- 填空题。
- 计算题。
- 简答题。
- 证明题。
- 作图题。
- 材料题或阅读理解。
- 复合题。
- 通用题。

复合题本身只有一个题目身份，每个小问可以有不同题型。

### 6.2 手机作答

| 题型 | 作答交互 | 判题边界 |
|---|---|---|
| 单选 | 选择一个选项 | 可自动判题 |
| 多选 | 选择多个选项 | 可按集合自动判题 |
| 判断 | 正确或错误 | 可自动判题 |
| 单空或多空填空 | 逐空输入 | 可按可接受答案自动判题 |
| 计算 | 文字或公式输入 | 可分析答案和步骤，不承诺完全批改 |
| 简答、证明 | 文字或公式输入 | 保存并分析，最终结果允许复核 |
| 作图 | 拍照提交 | 保存图片，人工或后续能力复核 |
| 材料、复合 | 按小问逐个作答 | 每个小问按自身题型处理 |

### 6.3 电子墨水屏

- 本轮只读。
- 一道题只生成一页。
- 学生回手机作答。
- 题目页不显示标准答案、解析或冲突标记。

## 7. 分类与学习状态

### 7.1 分类

分类允许一道题有多个值：

- 错题。
- 普通题。
- 经典题。
- 扩展题。
- 易错题。
- 重点题。
- 自定义分类。

默认规则：

- 用户从疑似错误候选中导入，默认添加“错题”。
- 用户主动选择系统判断正确的题，默认添加“普通题”。
- 经典、扩展、易错和重点题不默认由模型添加。

### 7.2 学习状态

- 未学习。
- 待复习。
- 练习中。
- 需巩固。
- 已掌握。

默认规则：

- 新导入错题进入“待复习”。
- 用户主动选择录入的答对题进入“未学习”，不立即进入到期队列。
- 其他题根据是否开始学习进入对应状态。
- 分类变化不等同于掌握状态变化。

## 8. 标准答案设计

### 8.1 三类答案

1. 学生原答案：照片中识别或用户录入的原始作答。
2. 系统建议答案：模型或工具计算出的建议。
3. 用户最终答案：用户核对后的正式标准答案。

界面必须避免让用户误以为系统建议已经是最终答案。

### 8.2 冲突状态

当用户最终答案与系统建议不等价时：

```text
系统建议：A
你的答案：B
两者不一致，请确认使用哪个作为标准答案
```

用户操作：

- 保留我的答案。
- 返回修改。

用户保留自己的答案后：

- 导入继续。
- 题目保留“标准答案与系统建议不一致”标记。
- 该标记进入待复核筛选。
- 复习题面不显示该标记。

如果系统无法可靠判断答案是否等价，也应进入待复核，而不是强行判为一致。

### 8.3 无法生成答案

- 显示“系统未能生成标准答案”。
- 允许手填或暂缺。
- 暂缺题标记“标准答案待补充”。
- 不得编造答案。

## 9. 来源设计

### 9.1 候选展示

- 默认最多 3 个。
- 按可验证性和匹配程度排序。
- 每个候选展示足够的定位信息。
- 低匹配候选明确标记“来源不确定”。

### 9.2 用户确认

用户可以选择：

- 采用某个候选。
- 修改候选信息。
- 手动填写来源。
- 暂不确认来源。

### 9.3 状态

- 未搜索。
- 有候选待确认。
- 已确认。
- 用户填写待核验。
- 未找到可靠来源。

“有候选”不等于“已确认”。

## 10. 图片设计

### 10.1 用户看到的内容

- 完整扫描原图。
- 当前题目区域。
- 优化后的题目图片。
- 去作答痕迹版本，仅在生成成功且用户可选时显示。

### 10.2 默认选择

- 清晰图片优先使用优化图。
- 优化图出现内容缺失、图形变形、文字不可读或黑块增加时回退原图。
- 手写和批改痕迹默认保守保留。
- 题目自带几何线、标签和必要辅助线不能被删除。

### 10.3 用户控制

- 查看原图。
- 查看优化图。
- 对比两者。
- 将原图设为复习显示图。
- 恢复自动优化结果。

## 11. 扫描导入与题库的关系

### 11.1 扫描中

- 使用本次扫描编号 1～N。
- 红线标记疑似错题。
- 默认不选。
- 残缺或严重不确定题默认不选。
- 支持全选、全部错题、取消全选。

### 11.2 确认后

- 只导入用户选中的题目。
- 系统建议答案、题型和来源显示在确认页。
- 用户确认答案冲突后才可继续。
- 批量导入显示成功和失败数量。

### 11.3 导入后

- 扫描候选状态变为“已导入”或“导入失败”。
- 正式题库生成对应题目。
- 原图和题目区域保持关联。
- 重试只处理失败项。

## 12. 查找与筛选

### 12.1 搜索

搜索应覆盖：

- 题干。
- 选项。
- 小问。
- 知识点。
- 来源。
- 用户标签。

纯图片题应能通过图片相关文字、知识点、来源或用户标签找到。

### 12.2 筛选

支持：

- 分类，可多选。
- 题型。
- 学习状态。
- 学科和知识点。
- 来源及确认状态。
- 标准答案待补充或待复核。
- 内容完整度。
- 图片可用性。
- 电子墨水屏适配状态。
- 扫描批次和时间。

### 12.3 排序

- 最近编辑。
- 最近导入。
- 学习状态优先级。
- 复习到期时间。
- 知识点。
- 来源。

## 13. 重复题设计

### 13.1 同一次扫描

- 同一候选重复导入必须被阻止。
- 用户调整候选框后仍识别为同一题时，应复用同一候选身份。
- 导入结果必须保持唯一。

### 13.2 跨扫描

- 发现高度相似题时提示“可能已存在”。
- 展示已有题的摘要和来源。
- 用户选择“仍然新建”“查看已有题”或“取消”。
- 系统不得自动合并或删除。

## 14. 异常状态

### 14.1 题目内容异常

- 内容残缺：默认不入批量选择，手动选择需要确认。
- 图片缺失：优先显示文字；文字也缺失时标记“需补图”。
- 图文顺序丢失：禁止保存为看似完整的错误题目，退回确认页。

### 14.2 答案异常

- 系统答案生成失败：允许用户填写或暂缺。
- 答案冲突：明确提示并记录。
- 答案变体不确定：进入待复核。

### 14.3 来源异常

- 无来源候选：显示“未找到可靠来源”。
- 来源候选低匹配：显示不确定性。
- 来源冲突：由用户选择或暂不确认。

### 14.4 图片异常

- 原图缺失：保留文字，提示补图。
- 优化图失败：回退原图。
- 派生图损坏：自动尝试原图。
- 删除失败：题目先保持可读，进入待清理状态。

### 14.5 导入异常

- 部分成功：成功项保留，失败项可重试。
- 重复提交：返回已有结果。
- 服务重启：已成功项不重复，未完成项标记待恢复。

## 15. 隐私与数据边界

- 图片默认保存本机。
- 上传图片后直接发送到内部 OCR Service，不显示二次确认。
- 图片不发送给外部多模态模型；纯文本模型只接收 OCR 文字、坐标和置信度。
- 首轮整页识别需要发送整页时，文案必须说明。
- 后续图片优化优先只处理用户选中题目区域。
- 普通日志不记录题目正文、答案和图片内容。
- 删除题目时一并处理该题独占的图片和派生内容。
- 全量删除覆盖扫描候选、暂存图片和正式题库。
- 题库本机备份必须包含原图和优化图。

## 16. 模块边界

| 模块 | 负责 | 不负责 |
|---|---|---|
| 题库 | 正式题目、内容、答案、分类、来源、修订和查询 | 扫描临时状态、学习策略 |
| 扫描导入 | 扫描任务、候选、选择、确认和导入编排 | 维护第二份正式题目 |
| 学习 | 作答、提示、掌握、复习计划 | 修改题库中的题目事实 |
| 电子墨水屏 | 单页排版、适配状态、设备帧 | 保存另一份题目数据 |

题库先作为独立功能模块实现。当前没有多用户、多设备同步和高并发证据，不立即拆微服务；未来具备真实扩展需求时再评估。

## 17. 产品验收重点

### 17.1 用户能感知的通过标准

- 题库只有一个“全部题目”列表。
- 切换错题、经典题、扩展题时，不产生重复题。
- 同一题可以同时有多个分类标签。
- 题目学习状态独立于分类。
- 答对题可以主动入库，但不会自动变成“已掌握”。
- 题目能够正确显示题干中的图片、选项和复合小问。
- 用户可以查找、筛选和修改题目。
- 原图和优化图都可查看和恢复。
- 标准答案冲突有明确提示并能追溯。
- 来源最多 3 个且必须确认。

### 17.2 不可接受的体验

- 把错题和普通题保存成两份互相不同步的数据。
- 用户切换分类后，学习记录丢失。
- 图片被固定在题目末尾，失去原始阅读位置。
- 系统建议覆盖用户答案。
- 自动优化覆盖原图。
- 题库中混入扫描候选或未选中的题。
- 题目内容被静默截断后仍显示为可复习。

## 18. 当前不做

- 题库微服务拆分。
- 教师端和家长端账号。
- 多设备实时同步。
- 跨题库自动合并题目。
- 电子墨水屏多页题目。
- 主观题完全自动可靠判分。
- 自动生成无限扩展题。

## 19. 后续讨论入口

- 固定真实试卷素材和识别准确率门槛。
- 固定电子墨水屏图片质量验收样本。
- 开发给出补充图片数量上限和具体适配算法说明。
- 人工确认题库来源数据是否可接入外部检索。
