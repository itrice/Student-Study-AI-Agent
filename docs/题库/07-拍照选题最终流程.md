# 拍照选题最终流程

> 版本：1.0
> 日期：2026-11-26
> 实现分支：`codex/question-scan-box-confirm`
> 实现提交：`a8542b1 refactor: unify photo scan flow and reset after import`
> 状态：当前实现，后续产品、开发与 QA 文档以本文的拍照选题流程为准

## 1. 唯一现行入口

拍照选题页面只保留一个入口：

```text
选择或拍摄图片
```

“录入错题”中的“拍照录入”也直接进入同一流程。

一次只选择或拍摄一张作业页。用户选择图片后：

1. 加载并显示原图。
2. 内部 OCR 只识别一次，返回原始文字字块。
3. 复用现有纯文本模型的题目边界逻辑，将字块聚合为完整题目。
4. 页面只显示聚合后的整题框，不显示行级 OCR 字块框。

## 3. 图片和题框交互

### 3.1 蒙层

- 图片加载后始终显示浅灰蒙层，透明度为 `0.22`。
- 当前获得焦点的题框内部不显示蒙层。
- 没有任何题框获得焦点时，整张图片覆盖浅灰蒙层。
- 蒙层随题框移动和缩放同步更新。

### 3.2 题框

- 边框为 `4px` 红色圆角边框。
- 题框支持整体拖动和四角缩放。
- 只有当前获得焦点的题框显示角点并允许移动、缩放。
- 点击其他区域、切换焦点或窗口失焦后，角点立即消失，题框不可继续调整。
- checkbox 勾选状态不等于题框调整焦点。

### 3.3 编号和 checkbox

- 多题模式下每个整题框显示顺序编号和 checkbox。
- 编号按从上到下、同高度从左到右排列。
- checkbox 使用半透明样式；题号使用轻微白色描边，避免大面积白底遮挡原图。
- checkbox 只控制是否提交该题框，不控制是否可调整。

## 4. 单题和多题模式

默认模式为“单题”。

### 4.1 单题模式

- 只显示距离图片中心最近的完整题目框。
- 成功定位至少一道题后，“确认分析”可用。
- 确认后只分析中央整题框。

### 4.2 多题模式

- 显示全部聚合后的完整题目框。
- 至少勾选一个 checkbox 后，“确认分析”才可用。
- 确认后只分析勾选题目。
- 保留实际题号；例如页面框序号为 1、2、3 时，候选仍可为第 6、7、8 题。

“确认分析”位于“题目框确认”标题最右侧。

## 5. 确认后的 OCR 复用

每个题目框包含：

- 当前区域 `region`。
- 初始区域。
- 该题全部原始字块 `sourceBlockIds`。

### 5.1 未修改题框

- 不重新发送图片给 OCR。
- 复用首次 OCR 中属于该题的全部字块。
- 使用这些文字、坐标和置信度执行现有单题分析。
- 不得只取第一行；跨行题目必须使用全部字块。

### 5.2 已移动或缩放题框

- 从原图按新区域重新裁剪。
- 对该区域重新调用内部 OCR。
- 再执行现有小问、学生答案、标准答案和题型分析。

### 5.3 自动回退重做 OCR

以下情况即使区域未变化也必须重做 OCR：

- 缓存 OCR 缺失。
- 缓存文字为空。
- 字块坐标无效。
- 置信度低于当前阈值。
- 部分 `sourceBlockIds` 找不到对应字块。

题框恢复到与初始区域完全相同的坐标后，可重新视为未修改。

## 6. 接口

### 6.1 `POST /api/attachments/:id/ocr-boxes`

返回两层数据：

- `blocks[]`：原始 OCR 字块，仅用于缓存和后续分析，不直接显示。
- `questions[]`：聚合后的整题目区域。

`questions[]` 字段：

- `id`
- `questionNo`
- `text`
- `confidence`
- `region`
- `pendingReasons`
- `sourceBlockIds`

### 6.2 `POST /api/attachments/:id/ocr-boxes/confirm`

请求主要字段：

- `scanMode`：`single | multi`
- `selections[]`
  - `groupId`
  - `questionNo`
  - `sourceBlockIds`
  - `region`
- `ocr`
  - OCR 元数据
  - 图片尺寸
  - 全部原始字块

响应字段：

- 现有扫描任务 `scan`
- `analyzedCount`
- `failedCount`
- `cachedCount`
- `reOcrCount`
- `results`

确认成功后进入现有候选题目页。用户仍需逐题核对并确认后才能导入题库。

原始 `/api/questions/scans`、分析、选择、导入等接口继续保留，用于兼容和后续候选流程，但不是拍照选题的唯一页面入口。

## 7. 导入成功后的页面重置

所有选中题目全部导入成功后：

- 清除扫描原图 `src`。
- 隐藏题目框确认区域。
- 清空题框、OCR 缓存和选中状态。
- 清除当前扫描任务。
- 恢复单题模式。
- “确认分析”恢复禁用。
- 隐藏候选题目页。
- 显示默认上传界面。
- URL 回到 `#scan`。
- 页面滚动回上传区域顶部。

部分成功、部分失败时不清空候选页，用户继续处理失败项。

## 8. 产品与工程边界

- 当前一次只选择或拍摄一张作业页。
- 旧“1 张主图 + 最多 2 张补充图”不属于当前 UI 流程。
- 图片只发送内部 OCR。
- 纯文本模型只接收 OCR 文字、坐标和置信度。
- 不新增数据库迁移。
- 不新增依赖。
- 不修改 CI/CD、Kubernetes 或部署流程。
