## 更新规则

每次实现完成后，必须按以下顺序更新：

1. 将实际完成的子项状态改为“已完成”。
2. 填写完成日期和可复现的验证证据。
3. 将新增问题登记到“实施完成记录”或任务明细。
4. 更新“当前阶段”和“下一步任务”。
5. 只有满足阶段验收条件后，才能把主阶段标记为“已完成”。
6. 未完成、未验证或仅写代码但未通过检查的项目不得标为“已完成”。
