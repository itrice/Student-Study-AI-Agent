# M5 知识库与检索说明

> 版本：2026.11.3
> 教材基线：人教版六年级（上册/下册）
> 验收状态：验收者-ark 复验通过（2026-11-10）
> 当前审核状态：项目自检 `self_reviewed`，任课教师最终签字待完成

## 1. 目标

M5 让诊断、提示和作答评价建立在可审计的知识内容上，而不是只依赖模型记忆或关键词规则。首版知识库满足以下要求：

- 覆盖 12 个六年级数学重点知识点。
- 每个知识点包含标准名称、别名、教材单元、前置知识、核心概念、方法步骤、适用条件、常见错误和典型例题。
- 每段内容都可以追溯到来源、版本和审核状态。
- `search_knowledge` 支持按知识点精确检索，也支持按学生自然语言、别名和关键词全文检索。
- 覆盖不足时明确返回 `not_covered` 或 `insufficient`，不编造来源。

单元边界说明：

- “位置与方向”按人教版六年级上册第2单元《位置与方向（二）》组织，只覆盖用方向和距离确定位置、描述路线；数对属于五年级《位置》，不放在本卡片中。
- “数与形”按六年级上册第8单元《数学广角——数与形》组织，例题使用连续奇数、正方形数和分数数列，不使用其他年级的点阵或火柴棒专题。
- “平均数”不属于六年级上册第7单元《扇形统计图》的内容，因此不登记为该知识点的别名或关键词；查询“平均数”会返回 `not_covered`，而不是用扇形统计图片段冒充答案。

## 3. 数据模型

数据库迁移 v7 新增或扩展：

| 表 | 用途 |
|---|---|
| `knowledge_points` | 知识点标准目录，扩展别名、单元、前置知识、关键词、方法、常见错误、内容版本和审核状态 |
| `knowledge_sources` | 来源记录，包含来源键、类型、标题、出版方、版本、定位、说明和核验日期 |
| `knowledge_chunks` | 可检索知识片段，片段类型为概念、方法、条件、常见错误和例题 |
| `knowledge_reviews` | 按内容版本记录审核清单结果和审核人 |
| `knowledge_chunks_fts` | SQLite FTS5 全文索引，使用中文字符和二元组分词 |

内容由 `src/knowledge/catalog.js` 定义。仓储启动时调用 `syncKnowledgeBase()`，按知识点内容指纹比对并幂等更新片段、来源、审核记录和全文索引。内容修改后无需新增 schema 迁移，但必须更新内容版本并重新评测。

## 4. 检索策略

1. 如果传入 `knowledgePoint`，按标准名称或别名精确返回该卡片。
2. 否则先计算名称、别名、关键词和二元组重合度，再用 FTS5 命中补充知识点和片段分数。完整名称和完整别名优先于单字名称的部分匹配，避免“圆”压过“圆柱与圆锥”。
3. 单字别名支持精确命中；`π` 等希腊字母按独立符号建立索引，不会因为长度小于 2 被丢弃。
4. 最多返回 3 个知识点；每个知识点默认返回核心概念、方法与步骤和最相关的第三个片段。
5. 最高分低于 18 视为 `not_covered`；低于 45 视为 `insufficient`；其余为 `covered`。
6. 每个片段返回 `citation`，Agent 只能引用 `items[].citations` 中的字符串。

## 5. 来源与引用

首版使用两类来源：

- `self-authored-summary-v1`：项目自编六年级数学知识摘要（2026.11）。依据教材单元结构自编，不是教材原文。
- `renjiao-outline-v1`：人教版六年级数学教材单元目录（人工核对）。仅记录单元名称和顺序，不摘录教材正文。

引用格式：

```text
项目自编六年级数学知识摘要（2026.11）· 圆 / 核心概念 [self-authored-summary-v1]
```

任何知识讲解至少关联一条引用。覆盖不足时来源数组为空，并在证据中说明需要教师补充；禁止用模型记忆伪装成教材结论。

## 6. 审核流程

1. 内容编辑：在 `src/knowledge/catalog.js` 更新卡片、片段或例题。
2. 自检：运行 `node --test` 和 `node scripts/evaluate-m5-knowledge.js`。
3. 审核：按 [知识内容审核清单](KNOWLEDGE_REVIEW_CHECKLIST.md) 逐项核对。
4. 教师签字：由任课教师确认术语、单元、例题答案和来源；通过后将 `reviewStatus` 改为 `teacher_reviewed`。
5. 发布：保留旧内容版本和审核记录，不覆盖历史引用。

当前所有卡片为 `self_reviewed`。这表示内容、例题答案、单元映射和来源已完成项目自检，不等同于教师签字。

## 8. 扩展方式

新增知识点时：

1. 在 `KNOWLEDGE_CARDS` 增加卡片，至少包含 3 个别名、1 个前置知识、3 条方法步骤、3 条常见错误、5 类片段和 2 个例题。
2. 为每个片段指定 `sourceKey`，禁止匿名内容。
3. 在 `KNOWLEDGE_EVALUATION_CASES` 增加至少 3 道题。
4. 运行测试和评测，确认 Top-3 不低于 90%、来源覆盖率为 100%。
5. 在审核清单中登记新的内容版本和审核状态。

## 9. 当前限制

- 内容为项目自编摘要，尚未完成任课教师最终签字。
- 知识库不覆盖“平均数”等非六年级内容；这类查询会明确返回 `not_covered`。
- 评测集规模较小，尚未覆盖真实学生的全部口语化表达。
- 首版不引入向量数据库；只有全文检索 Top-3 持续低于目标时再评估 Embedding。
- 知识卡片包含典型例题答案，用于知识讲解；复习提示仍由答案泄露拦截器保护当前题目的标准答案。
