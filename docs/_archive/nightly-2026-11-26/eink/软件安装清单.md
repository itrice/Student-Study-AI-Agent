## 八、重建步骤（换机或清理后照这个来）

1. `pip install platformio`（自带 esptool / pyserial 依赖，若单独需要再 `pip install esptool pyserial`）
2. `python -m platformio platform install espressif32@6.9.0`
3. 运行 `D:\Andy\Projects\esp32\mistake-display\toolchain\download.py` 拉核心包与编译器（走代理、带断点续传）
4. 运行 `toolchain\install_packages.py` 解包成 PlatformIO 包（含 `.piopm`）
5. **手工确认** `framework-arduinoespressif32\.piopm` 里 `spec.owner` 是 `platformio`，`version` 是 `3.20017.0`——写错就报 `MissingPackageManifestError` 或反复重装
6. 运行 `toolchain\make_placeholders.py` 建占位包
7. 运行 `toolchain\fetch_libs.py` 拉 Seeed_GFX / ArduinoJson 到 `lib/`
8. `python -m platformio run --project-dir D:\Andy\Projects\esp32\mistake-display`
9. 烧写：按一下载板 RESET，然后 `python toolchain\flash.py`
